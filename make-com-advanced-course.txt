PHẦN 1 | ADVANCED ARCHITECTURE
"Từ Scenario Đơn Lẻ Đến Hệ Thống Thực Sự"
(~2.5 giờ)
────────────────────────────────────────────────────────────────

Bài 1.1 – Tư duy hệ thống vs tư duy scenario đơn lẻ
  - Vì sao 1 scenario khổng lồ là anti-pattern?
  - Nguyên tắc Single Responsibility cho automation
  - Vẽ sơ đồ kiến trúc trước khi mở Make.com

Bài 1.2 – Sub-scenarios & Scenario Chaining
  - Gọi scenario từ scenario khác (như function call)
  - Truyền data giữa scenarios qua JSON payload
  - Pattern: Orchestrator scenario + Worker scenarios
  - Thực hành: tách Lead Pipeline thành 4 sub-scenarios

Bài 1.3 – Shared Data Layer
  - Data Store nâng cao: index, search, batch operations
  - Dùng Google Sheets / Airtable làm "database" cho hệ thống
  - Tránh race condition khi nhiều scenarios cùng ghi dữ liệu

Bài 1.4 – Queue Pattern (xử lý khối lượng lớn)
  - Vấn đề: 500 webhooks đến cùng lúc → crash
  - Giải pháp: Buffer queue bằng Data Store + Scheduled trigger
  - Thực hành: build queue system cho email campaign

PHẦN 2 | PRODUCTION-GRADE ERROR HANDLING
"Scenario Của Bạn Phải Sống Sót Được Khi Mọi Thứ Sai"
(~2 giờ)
────────────────────────────────────────────────────────────────

Bài 2.1 – Các loại lỗi trong Make.com
  - Connection errors    : API bên ngoài timeout hoặc down
  - Data errors          : field trống, sai kiểu, null pointer
  - Logic errors         : scenario chạy đúng nhưng kết quả sai
  - Rate limit errors    : gọi API quá nhiều lần/phút

Bài 2.2 – Error Handler Module (Break / Resume / Rollback)
  - Break   : dừng, log lỗi, không làm gì thêm
  - Resume  : bỏ qua bundle lỗi, tiếp tục bundle sau
  - Rollback: hoàn tác tất cả (dùng khi có transaction)
  - Quyết định dùng cái nào trong tình huống nào

Bài 2.3 – Retry Logic & Exponential Backoff
  - Tự build retry mechanism trong Make
  - Exponential backoff: 1s → 2s → 4s → 8s → alert
  - Dùng Data Store để track retry count

Bài 2.4 – Dead Letter Queue & Alert System
  - Bundle lỗi không xử lý được → lưu vào "dead letter"
  - Alert đa kênh: Telegram + Email khi có lỗi critical
  - Dashboard monitoring: Airtable/Notion làm error log

Bài 2.5 – Testing Scenarios Như Pro
  - Unit test từng module bằng mock data
  - End-to-end test với production-like data
  - Checklist trước khi bật scenario live

Bài 3.1 – HTTP Module Mastery

  - Xử lý pagination: tự động lặp qua nhiều trang kết quả

Bài 3.2 – Webhook Security & Validation
  - Xác thực webhook signature (tránh giả mạo request)

Bài 3.3 – Advanced Data Transformation
  - JSONata expressions cho complex data manipulation

Bài 3.4 – Working With Files
  - Download → Process → Upload file pipeline
  - Parse CSV, Excel, JSON files tự động
  - Generate PDF/document từ template + data
  - Xử lý images qua external API (resize, convert...)

Bài 3.5 – Custom Apps với Make SDK (giới thiệu)
